# KoraScope | كورة سكوب

نسخة أولية تجريبية (PWA) باللغة العربية.

## محتويات المشروع
- `index.html`: بنية الواجهة.
- `styles.css`: التصميم المتجاوب.
- `app.js`: التنقل والمفضلة وبيانات العرض التوضيحية.
- `manifest.webmanifest`: تعريف تطبيق الويب القابل للتثبيت.
- `sw.js`: التخزين المؤقت للعمل الأساسي دون اتصال.
- `icons/`: أيقونات التطبيق بصيغة SVG.

## مهم قبل الإطلاق
المباريات الموجودة حالياً بيانات توضيحية فقط وليست نتائج أو مواعيد حقيقية. لا تستخدمها لإخبار المستخدمين عن مباريات فعلية. يلزم ربط التطبيق لاحقاً بمزود بيانات كرة قدم مرخص، ومراجعة شروط الاستخدام والتكلفة وحدود الطلبات. الأخبار يجب أن تكون من مصادر تملك حق إعادة نشرها أو عبر روابط/ملخصات معتمدة.

## تجربة سريعة
افتح `index.html` في متصفح أو محرر يدعم معاينة HTML. لتجربة PWA والتثبيت والعمل دون اتصال، انشر الملفات على استضافة HTTPS مثل GitHub Pages.

## تجهيز APK لاحقاً
بعد نشر PWA على HTTPS، أدخل رابطها في https://www.pwabuilder.com ثم اختر Android package. اتبع خطوات التوقيع واحتفظ بمفتاح التوقيع وكلمات المرور في مكان آمن. إنشاء حزمة TWA يتطلب PWA منشورة على HTTPS. النشر في Google Play يتطلب حساب مطور مدفوع منفصل.
